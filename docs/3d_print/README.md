# S10 Piper 3D Printed Parts

This directory contains the SolidWorks source file for a 3D-printed structural part used in the S10 Piper assembly.

The part is intended to help mount the Orin, Piper arm, and related components on the S10 platform. Check the dimensions, fasteners, clearances, and load capacity against your own hardware before printing or operating the robot.

File:

- `leige3Ddayin.SLDPRT` — SolidWorks part source file.
